# 你是什么东西

「专业外壳 × 地狱内容」的 H5 反人格测试：30 道二选一，测出你的 16 种人格代号与专属物种档案。

## 运行

纯静态页面，无需构建。本地预览：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 结构

- `index.html` / `css/` / `js/` —— 封面、答题、结果、16 人格画廊等页面与逻辑
- `assets/animals/` —— 16 种人格动物 SVG
- `build/` —— 单文件构建脚本与产物（`python build/build_single.py`）
- `deploy/` —— 部署副本（GitHub Pages 可直接使用）
- `0X-*.md` —— 完整产品文档（定位、规则、题目、文案、UI 规范、验收与部署指南）

## 玩法规则

- 4 维度（EI / SN / TF / JP），每维 7 题计分，总分 -7…+7，无平局
- Q15、Q30 为不计分彩蛋题
- 结果页展示人格代号、动物大图、地狱判决、处方与物种档案，可生成分享长图
